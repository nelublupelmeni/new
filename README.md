Напишите программу, которая применяет к изображениям эффекты, имитирующие старые фотографии.

Необходимо разработать программу, которая:
1. Позволяет выбрать одно или несколько изображений для обработки.
2. Применяет настраиваемые эффекты «старения»:
    - добавление шума;
    - тонирование в сепию;
    - потертости и царапины (наложение текстур/артефактов).
3. Предоставляет отдельные параметры управления степенью каждого эффекта (интенсивность шума, сила тонировки, плотность/размер/распределение потертостей и царапин).
4. Обеспечивает предпросмотр результата до сохранения.
5. Сохраняет обработанные изображения на устройство, не искажая исходные пропорции и с выбором формата/качества.
В программе должно быть предусмотрено:
1. Независимая настройка параметров для каждого эффекта (вкл/выкл и численные/ползунковые значения)
2. Возможность сброса параметров к значениям по умолчанию и повторного применения.
3. Предпросмотр с быстрым переключением «до/после» и требования

Результатом выполнения домашнего задания является ваш код, а также Docker Image с вашим кодом.
