# Photo Aging App 

## 1. Описание программы

### Что делает программа

Photo Aging App - это веб-приложение для применения эффектов "состаривания" к фотографиям. Программа имитирует внешний вид старых фотографий через наложение различных визуальных эффектов.

### Основные возможности

- **Многопользовательский интерфейс**: Загрузка и обработка нескольких изображений одновременно
    
- **Эффекты старения**:
    
    - **Сепия**: Тонирование фотографий в коричневые тона с регулируемой интенсивностью
        
    - **Шум**: Добавление зернистости для имитации плёночного шума
        
    - **Царапины**: Наложение случайных царапин с настройкой плотности, размера и прозрачности
        
- **Предпросмотр**: Мгновенный просмотр результатов с переключением "до/после"
    
- **Гибкое сохранение**: Экспорт в форматах JPG, PNG, WebP с выбором качества
    
- **Интуитивное управление**: Ползунки для точной настройки параметров эффектов
    

### Ограничения

- Максимальный размер загружаемого файла: 16MB
    
- Поддерживаемые форматы ввода: JPEG, PNG, WebP, BMP
    
- Обработка выполняется на сервере, требуется стабильное интернет-соединение
    
- Царапины генерируются из предустановленного набора PNG-изображений

## 3. Запуск и загрузка данных

### Локальный запуск

```
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python app.py
```
### Docker запуск

```
# Сборка образа
docker build -t photo-aging-app .

# Запуск контейнера
docker run -p 5000:5000 photo-aging-app
```

### Загрузка изображений

1. Откройте приложение в браузере (`http://localhost:5000`)
    
2. Нажмите "Выберите файлы" для загрузки изображений
    
3. Выберите через диалоговое окно
    
4. Используйте элементы управления для настройки эффектов
    
5. Скачайте результат через меню "Скачать результат"
    

## 4. Используемые инструменты

### Основные технологии

- **Backend**: Flask (Python веб-фреймворк)
    
- **Frontend**: HTML, CSS, JavaScript (нативный)
    
- **Обработка изображений**: OpenCV, Pillow (PIL)
    
- **Математические вычисления**: NumPy
    

### Библиотеки Python

python

```
flask==2.3.3          # Веб-фреймворк
opencv-python==4.8.1  # Компьютерное зрение
pillow==10.0.0        # Обработка изображений
numpy==1.24.3         # Научные вычисления`
```

### Архитектура приложения


